# BET — Netlify Preview

This is a zero-build static preview of BET. It is made specifically so you can upload it to GitHub and deploy to Netlify immediately, without a database, environment variables, npm or a build step.

## Preview contains
- landing page
- product dashboard
- Ask BET demo
- Experience Graph
- entrepreneur profile with followers and earned BET Business Mentor status
- Business Impact
- Live Research
- responsive mobile layout

All companies, outcomes and numbers are illustrative demo content.

## Deploy to GitHub + Netlify
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. In Netlify: Add new site → Import an existing project → GitHub.
4. Choose this repository.
5. Build command: leave empty.
6. Publish directory: `.`
7. Deploy.

You can also drag this entire folder into Netlify Drop for an immediate preview.
